Темы курса по питону

18 мая 2023 г. · 2 минуты · Alexander Schepanovski

Интерактивный Шелл, переменные - простенький калькулятор с переменными

Базовый ввод-вывод - привет, юзернейм. Google “python print function”

Типы - программа расчётов, например, объем стакана. Целые и дробные числа. Преобразование str -> int, чтобы ввести число. Задание 1: добавить поддержку дробного диаметра. Str -> float. Задание 2: float -> int. Спросить число и округлить его?

Исключения - получаем ошибку в предыдущей программе вводя не число. Ошибка вс исключение вс баг.

Условное ветвление - проверка ввода перед преобразованием в число, проверка, что имя введено и состоит из букв (не из цифр)

Работа со строками - .isdigit() а также преобразование имени .title(), .strip(), .upper(). Функции len(). Как искать доки.

Работа со строками. Индексы - Попытка name[0].isupper()

Переменные и константы - PI

Общие соображения:

  • Перемежать практику и теорию. В частности, не давать сразу зубодробительно энциклопедических перечислений: всех типов, литералов, операторов, конструкций, методов какого-то класса и т.п.
  • Давать уроки так, чтобы по результатам каждого можно было сделать что-то полезное и новое с осмысленным использованием показанных возможностей.
  • Урок должен иметь в конце практические задания.
  • Опционально давать ссылки для изучения.
  • Примеры должны быть иллюстративны, а не абстрактны.
  • подталкивать учеников гуглить и читать доки.
